# Panel setup

<figure><img src="../.gitbook/assets/настройка-панели.png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
Below is the general logic of setup — it's roughly the same for all panels. The specific button names differ, so cross-check against your panel's current instructions.
{% endhint %}

<h2 align="center">1️⃣ <mark style="color:green;">Buying a subscription</mark></h2>

#### The subscription is bought in the panel's bot. You go in, pick a plan by number of accounts, pay, and get a key or access to a dashboard.

* #### [**DM Panel**](https://t.me/dmpanelsbot?start=6810487864)
* #### [**FSM Panel**](https://t.me/moonlighter_shop_bot?start=6810487864)
* #### [**Manager Standard**](https://t.me/standard_arb_bot?start=jjjyhhff)

{% hint style="success" %}
Don't grab a thousand-account plan right away. Take the smallest one, run a cycle, make sure everything works and it's comfortable for you — and only then scale up.
{% endhint %}

<h2 align="center">2️⃣ <mark style="color:green;">Installing the client</mark></h2>

1. #### Download the client **only from the link in the panel's official bot**.
2. #### Add the folder to your antivirus exclusions — otherwise it'll cut out the spoofer.
3. #### Install to a path with no Cyrillic characters.
4. #### Run it as administrator.

{% hint style="warning" %}
Panel builds from forums, chats and "from a friend" are the classic way whole farms get drained. Download only from the bot you have a subscription with.
{% endhint %}

<h2 align="center">3️⃣ <mark style="color:green;">Loading accounts</mark></h2>

#### Panels usually take accounts as a text list of `login:password` plus a folder with the maFiles. Check the format in your specific panel's instructions — if you mix up the separator, the import simply won't go through.

#### What to check before importing:

* #### No empty lines or extra spaces in the list.
* #### The maFile names match the logins.
* #### Accounts aren't locked and aren't sitting out the week of restriction after linking SDA.

<h2 align="center">4️⃣ <mark style="color:green;">Main settings</mark></h2>

### <mark style="color:blue;">Streams</mark>

#### The number of clients running simultaneously. Set it to your hardware's capacity: not enough RAM — everything starts crashing. Start small and add, watching the load in Task Manager.

### <mark style="color:blue;">Farming mode</mark>

#### You choose the mode the matches run in. It determines both the speed and the risk profile.

### <mark style="color:blue;">Proxies</mark>

#### If the panel supports them — set them up. The rule is simple: don't hang a hundred accounts on one address.

### <mark style="color:blue;">Spoofer</mark>

#### Handles spoofing the hardware parameters. On by default — don't turn it off unless you understand why.

### <mark style="color:blue;">Collecting and sending the drop</mark>

#### You enter the trade link of the [**collector account**](../drop/khranilki-i-sborshiki.md), enable auto-collect and auto-send. This is the whole reason automation exists — you're not going to collect the drop from three hundred accounts by hand.&#x20;

#### An important note on collecting and sending the drop: not long ago, a couple of months back, bots and farm accounts numbering around 1 million were wiped, and the pattern was — trades. The current meta in farms is that people either collect the drop once every 3–4 weeks into a vault, and the number of vaults is also large. You used to be able to use 1 vault per 500 accounts; now it's better to have 100 vaults per 500 accounts — I think it's clear why. Personally I don't really use vaults; I sell all the drop on the same accounts and buy TF2 keys. Yes, I lose some earnings, but I figure I might potentially stay out of a future VAC wave.



<h2 align="center">5️⃣ <mark style="color:green;">First launch</mark></h2>

1. #### Launch **5–10 accounts**, no more.
2. #### Watch whether games are found and whether matches reach the end.
3. #### Check the system load.
4. #### Make sure the drop actually lands on the collector.
5. #### Only after that bring up the rest.

{% hint style="success" %}
Half an hour on a test run saves you two days of figuring out "why nothing got farmed". Don't skip this step.
{% endhint %}
